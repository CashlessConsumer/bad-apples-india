📋 Report an Incident

Submit a police misconduct incident for review. All submissions are reviewed by editors before publication. Fields marked * are required.

Include date/time, what you witnessed or know, and any FIR/complaint numbers if available.
Publicly accessible URL showing the incident. X/Twitter posts, YouTube, or news articles preferred.
For now, submissions go through GitHub (requires account). Anonymous via email coming soon.
Prefer direct submission? Open a GitHub Issue directly — or read the Constitution before submitting.
Inspired by Aaron Swartz's Bad Apples. Built for accountability — not harassment, not violence, not vengeance.
